🔒 POST-QUANTUM CRYPTOGRAPHY LAYER
🔑 Step 1 — Key Encapsulation
ML-KEM-768 (Kyber)
  • Server generates KEM keypair (pk, sk)
  • Client: (kem_ct, ss) = encap(pk)
  • Server: ss = decap(sk, kem_ct)
  • ss → HKDF-SHA256 → AES-256 key
  • Quantum-resistant vs Shor/Grover
pk: 1184B | sk: 2400B | ct: 1088B
▾
🔐 Step 2 — Encryption
AES-256-GCM
  • nonce = random 12 bytes
  • AAD = client_id ‖ round_num
  • ct = AES-GCM(key, update, AAD)
  • GCM tag → integrity + auth
  • AAD mismatch → InvalidTag error
▾
✍️ Step 3 — Digital Signature
ML-DSA-65 (Dilithium)
  • Payload = client_id ‖ round_num ‖ kem_ct ‖ nonce ‖ ciphertext
  • σ = DSA_sign(sk, payload)
  • Prevents replay / reorder / impersonation
  • Server verifies before decryption
pk: 1952B | sk: 4032B | σ: 2420B
▾

🛡️ SERVER — OptiGradTrust v4 Defense Mechanism
1) Cosine + Norm-Based Trust
📐 Cosine Similarity Score
Direction Alignment
cos_score = (cos(uᵢ, ¨u) + 1) / 2 ¨u = element-wise median update Maps cosine[-1,1] → [0,1]
📏 Blended Norm-Ratio Penalty
Self + Cross-Client Baseline
cross_ratio = ‖uᵢ‖ / median(‖uⱼ‖) self_ratio = ‖uᵢ‖ / median(own hist) ratio = 0.5×self + 0.5×cross norm_score = exp(-(ratio-1)² / 0.5)
  • Self-blend prevents non-IID false penalty
  • Gaussian peak at ratio=1 (normal)
⚡ Cosine Raw Score
Combined Gradient Score
cosine_raw = (1-λ)×cos_score + λ×norm_score λ = TRUST_NORM_PENALTY
2) Sign Consistency Gate + Loss
🚦 Sign Consistency Score
Gradient Direction Gate
sign_score = matching_signs / total_dims gate = 0.5 + 0.5 × sign_score ∈ [0.5, 1.0]
  • Honest (sign≥0.80): gate≈0.90–1.0
  • Attacker (sign≈0.40): gate≈0.70
  • Applied to ALL scoring modes
📉 Loss-Based Trust Score
Validation Loss Evaluation
loss_raw = exp(-10 × Δloss / base_loss) if Δloss ≤ 0: mild recovery ×1.05 if concentrated spike: ×0.5
  • Stratified rotating validation set
  • Per-class loss decomposition
  • Detects label-flip signature
🔀 Combined Score
Geometric Mean (Dual-Check)
raw_score = √(cosine_raw × loss_raw) Forces attacker to evade BOTH cosine + loss checks
⚙️ Score Sharpening + Adaptive EMA Update
🎯 Score Sharpening (v4)
raw_score = raw_score ^ 2.5 Honest (0.99→0.975): unchanged Suspicious (0.85→0.67): pulled down Widens gap, monotonic (no re-rank)
📈 Adaptive Alpha EMA
if drop > max(0.25, 2σ_hist): α = 0.6 (fast reaction) else: α = 0.2 (smooth) Tᵢ = (1-α)×Tᵢ_old + α×raw_score Clamp Tᵢ ∈ [TRUST_MIN, 1.0]
✂️ Trust-Gated Trimming (v4 — replaces norm-rank backstop)
Statistical Outlier Exclusion
z = (mean_T − Tᵢ) / std_T Exclude client if: z > 1.25 (z-threshold) AND gap > 0.05 (absolute)
  • Max trim: 40% of cohort
  • No trim during warm-up rounds
  • Trim nobody when cohort is homogeneous
  • Replaces old norm-rank that discarded 60% unconditionally
📊 Trust Weight Output
Normalised: T̃ᵢ = Tᵢ / ∑ⱼ Tⱼ FedAvg → trust_weights [T̃₁, T̃₂, …, T̃ₙ] Krum → krum_modifiers [2 − T₁, …] Manhattan → trust_weights [T₁, …, Tₙ]
⚙️ FINAL AGGREGATION
A — FedAvg + Trust
Trust-Weighted Average
w_combined = wᵢ × Tᵢ (element-wise) → normalize to sum=1 ΔW = ∑ᵢ w_combined_i × uᵢ
  • Low-trust clients auto down-weighted
  • Honest non-IID clients protected
B — Krum + Trust Modifiers
Byzantine-Resilient Selection
krum_score(i) = ∑ dist²(uᵢ, uⱼ) for n-f-2 nearest neighbours modifier = 2 − Tᵢ (low trust → higher score) → penalised in ranking Select m lowest-score updates
  • Multi-Krum selects top-m updates
  • Trust biases selection from attackers
C — Manhattan Distance + Trust
L1-Distance Outlier Weighting
dist_L1(uᵢ, ¨u_median) if dist > μ + σ_factor × σ: weight_i ×= 0.5 (outlier) final_weight_i = outlier_weight × Tᵢ (trust)
  • Reduces outlier contributions
  • Trust further down-weights suspects
  • Robust to Byzantine noise
🌐 Global Model Update
w_global(t+1) = w_global(t) + ΔW_aggregated
↓ Broadcast updated global model to all clients
